# LeanIMT+ vs SMT — real-data benchmark

Comparison of [`moica-revocation-leanimt-plus`](https://github.com/moven0831/moica-revocation-leanimt-plus) against the predecessor [`moica-revocation-smt`](https://github.com/moven0831/moica-revocation-smt) on live Taiwan MOICA G2 + G3 CRL data.

Generated by `bench/cmd/report` on `2026-05-14T04:40:32Z` (GOOS=darwin, GOARCH=arm64, NumCPU=8).

Reproduce: `make bench-real`. See [bench/README.md](README.md) for the env-var contract.

## Methodology

Both impls benchmark on a single fetch of G2 + G3 CRL DERs staged in `bench/.cache/` (path passed via `MOICA_BENCH_DER_DIR`); the benches refuse to run if it's unset, so neither side falls back to live HTTP. Each repo parses the same DERs, dedupes and sorts the revoked serials, then runs `go test -bench` (`-count=3` for fast benches, `-benchtime=3x` for build / hash-count).

Proof gen and verify share a fixed query set of `K=1024` serials per dataset, drawn with seed `42` — membership picks from revoked serials, non-membership picks distinct values guaranteed absent. Both repos consume the same `(seed, K)`, so the workload is bit-identical.

## Metric definitions

| Metric | Definition |
|---|---|
| Build time | `ns/op` for `InsertManySorted` (LeanIMT+) / `BatchAdd(value=1)` (SMT) over the full sorted serial list. |
| Proof gen / verify time | `ns/op` averaged across the 1024-query set. |
| siblings/op | Mean siblings array length per proof. LeanIMT+ varies (unpaired-right levels contribute no entry); SMT is fixed at `depth=128`. |
| proofBytes/op | `len(json.Marshal(proof))`. Wire formats differ across repos — compare orders of magnitude, not exact bytes. |
| allocs/op, B/op | `b.ReportAllocs()` allocations and bytes per op. |
| Hash counts | Poseidon-P256 `Hash2` / `Hash3` calls per op, captured in dedicated `HashCount_*` benches that wrap the hasher with an atomic counter (timing benches use the plain hasher to avoid counter overhead). |
| Snapshot size | `os.Stat` of the gzipped (`gz`) and uncompressed (`raw`) file from `snapshot.ExportFile`. SMT additionally exports `ExportBinary` (`bin.gz`). |
| Tree shape | Leaves include the LeanIMT+ sentinel at index 0, so `leaves = serials + 1`. Depth is `ceil(log2(leaves))` for LeanIMT+ and fixed at 128 for SMT. |

### Notes

- LeanIMT+ uses dynamic depth and `Hash2` only; SMT uses fixed depth 128 and `Hash3` for leaves.
- Build time is wall-clock for `InsertManySorted` (LeanIMT+) / `BatchAdd` (SMT) over deduped+sorted serials.
- Proof gen/verify times average over 1024 random queries with fixed seed; both impls use identical query sets.
- `proofBytes` is `json.Marshal` of the proof struct as-defined in each repo. Wire formats differ, so absolute byte counts are indicative, not normative.
- Hash counts are captured in dedicated benches with an atomic-counting hasher; main timing benches use the plain Poseidon hasher.
